# Techne's working records are English; learner prose is composed in the learning language

A French learner found lesson wording, quiz options and exercise statements awkward to read, a week after five writing rules had been adopted for lessons. The cause was not the learner's level. Techne kept its working records (`CURRENT.md`, `SESSION_LOG.md`, evidence lines) in the learning language, but in the skill's own English vocabulary: *probe* became « sonde », *timebox* « borne », *assisted* « assisté », and *the learner* stayed « le learner ». Techne rereads those records at every turn, so their calques flowed back into what it wrote to the learner. The lessons carried the same habit: their sections were titled by literal translation of the roles this skill lists (problem, mental model, worked example, checks).

Techne therefore writes its working records in English, in its own vocabulary, whatever the learning language. Everything addressed to the learner — lessons, questions, briefs, feedback, conversation — is composed directly in the learning language, never lifted from a record or translated from the skill. The writing rules now cover all of those texts, not only lessons.

## Consequences

- Records the learner never reads can use the skill's terms exactly, and learner-facing text has nothing to calque from.
- Existing workspaces keep their records in the learning language until each file is next rewritten; nothing is migrated in bulk.
- Evidence lines the state script writes itself are English, like the rest of the records.
- `DECISIONS.md` is now read at the start of every turn, so a writing rule approved with the learner survives the conversation it was decided in.
