# Learners hand-write every exercise, and Techne teaches no AI-assisted workflow

Techne is delivered by a coding agent and teaches a track about building LLM applications, so the obvious move would be to teach AI-assisted development and let the agent produce code. We decided the opposite: the learner writes every line of an exercise by hand, and no part of the curriculum teaches prompting or agent workflows for writing production code. The programme exists to rebuild technical adherence with the craft, which generated code erodes; the Applied AI track is about building AI systems, not about delegating one's own work to them.

## Consequences

- Techne may scaffold folders, dependencies, tests, and empty signatures, but never the implementation, and never edits an exercise file.
- When the learner is fully stuck, Techne explains the approach step by step and, as a last resort, shows a reference solution in the conversation to read and rewrite by hand; that work is recorded as not independent.
- Reviewing code one did not write — a genuinely valuable skill in the AI era — is deliberately left out of the programme, because the learner already practises it at work.
