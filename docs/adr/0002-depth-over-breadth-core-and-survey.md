# Depth over breadth: a demonstrated core and an explicit survey list

Sixty mornings cannot take forty subjects to mastery, so the programme splits subjects in two. The core is taken to demonstrated independence: TypeScript and JavaScript, React and Next.js, NestJS and backend, SQL and data modelling, DSA up to graphs, tests and debugging, applied architecture. The survey is covered for working literacy only — distributed systems, large-scale system design, and the day-to-day level of security, performance, observability, and delivery — and is grafted onto core exercises rather than taught in its own sessions.

Maths for engineering, dynamic programming and advanced DSA patterns, Product and communication as separate lanes, and Git and code review are out of the programme. The learner's goal is being better at a React/Node job, and they already practise Git daily. (Git and code review later joined the programme: see `0014-the-delivery-flow-joins-the-programme.md`.)

## Consequences

- Dropping dynamic programming weakens interview preparation, which the learner ranked second behind job performance; mock interviews in weeks 11–12 partly compensate.
- Coverage claims must stay honest: the mastery map shows survey subjects as literacy, never as mastery.
